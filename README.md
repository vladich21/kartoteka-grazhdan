# Картотека граждан

React + Vite + Ant Design. Графики на Recharts.

## Запуск

```bash
npm i
npm run dev
```

Сборка: `npm run build`

## Страницы

- `/` — дашборд (KPI + Recharts)
- `/registry` — список, фильтры, превью
- `/citizens/:id` — карточка с разделами
- `/params` — таблица параметров учета

Данные локальные, без бэка.
